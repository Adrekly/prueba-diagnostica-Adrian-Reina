# Problema 1: Analizador Léxico de Expresiones Aritméticas

Este script escrito en Python analiza una cadena de texto y clasifica cada uno de sus componentes léxicos (Tokens) siguiendo un sistema de reglas basado en expresiones regulares.

## Ejecución

No se requieren dependencias externas (librerías de terceros) para ejecutar este programa. Utiliza únicamente la librería estándar de Python `re`.

Para ejecutar el programa y ver los casos de prueba, posicionarse en esta carpeta y ejecutar en la consola:

```bash
python main.py
